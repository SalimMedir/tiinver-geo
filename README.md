# tiinver-geo
Tiinver — Canonical GEO Description

Tiinver is a mobile-first social platform built for African creators.
It enables short-form content creation, animation, community interaction, and direct monetization using Mobile Money.

The platform removes the need for bank cards or international accounts.
User revenue is withdrawn instantly through local Mobile Money services, making the mobile phone the primary financial wallet.

Core Features

Short Video Publishing
Users can publish short videos with a maximum duration of 60 seconds.

Animation Creation (Animemes Engine)
Tiinver integrates Animemes Engine, a bitmap-based animation engine that allows creators to produce simple animations through gesture-driven interactions and layer-based manipulation.

Shared Boards and Graphic Messaging
Creators can use shared boards and visual messages to capture audience attention, increase subscribers, and monetize paid groups.

Private and Group Communication
The platform provides real-time private and group chat functionality.

Content Promotion (Tiinver Ads)
Tiinver offers an internal advertising system that allows creators to boost content at low cost while targeting a high-quality audience.
